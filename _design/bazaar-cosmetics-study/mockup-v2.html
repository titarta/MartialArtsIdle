Spirit Bazaar v2 . skin cards + theme bundles procession-only, no tint, no equip-in-store, bundle packs added . 2026-05-27

Clearer brief: (1) tint cards are a bug - remove entirely; (2) every skin is the procession (first 3 stances readable, rest silhouetted to keep the surprise) - placeholder sprites today, real premium pixel art later; (3) no equip / unequip in the store - once bought, the card disappears and lives in Codex > Wardrobe; (4) add Fortnite-style theme bundles (cultivator + crystal + particles same theme, discounted).

Rule 1 . no tints
Drop the entire tint product line (Crimson / Verdant / Amethyst Path etc.). It was a bug - there's no recolor SKU.
Rule 2 . one card shape
Every skin uses the procession: t1-t3 in colored detail, t4-t13 in pure silhouette behind a soft mist veil. Same shape across all slots.
Rule 3 . store sells only
No equip / unequip here. Buy . disappear from store . equip in Codex > Wardrobe. Store stays focused on conversion.
Rule 4 . theme bundles
A "Frost Sect" pack = cultivator skin + crystal skin + particle pack at 20-25% off the sum-of-parts. Violet/purple chrome distinguishes from singles.
Singles Cosmetics aisle . skin cards
Each skin card is a procession. Header has name + slot tag (CULTIVATOR / CRYSTAL / etc.). Foot has stage counter + Buy CTA with explicit lotus-tagged price. No equip flow - the card vanishes the moment it's bought (goes to Codex). Already-owned skins never appear here.

What changes in code

Drop entirely:

  • The TINT_PREVIEW_FILTERS map and the tint-card branch in SpiritBazaarScreen.jsx's getPreview()
  • The simple CosmeticCard component (all the hue-rotate variants)
  • The cos_char_crimson/cos_char_verdant/cos_char_amethyst/cos_crystal_verdant/cos_crystal_amber/cos_particles_jade/cos_particles_violet/cos_bg_dawn/cos_bg_twilight data entries
  • The group.premium "Coming Soon" subsection rendering
  • The onEquip / onUnequip wiring in CosmeticCardProcession - equipping happens in Codex > Wardrobe now

Add / keep:

  • CosmeticCardProcession stays as the only cosmetic card shape - sells full-skin SKUs only
  • New BundleCard component for theme packs (violet chrome, 3 mini-processions, save-ribbon, total strike + bundle price)
  • New data shape in shopItems.js: { id, kind: 'bundle', theme, components: [skinId, skinId, skinId], cost, saveAmount } - the apply layer expands components on purchase and credits all three to inventory
  • After purchase: cosmetic disappears from the Bazaar list (filtered out by !inventory.isCosmeticOwned(id) at the section level) and surfaces in Codex > Wardrobe for equipping

Aisle order: Theme Packs first (deal-driver), then singles by slot (Cultivator / Crystal / Particles / Backdrop). Empty group = hidden entirely. No "Coming Soon" placeholders.
