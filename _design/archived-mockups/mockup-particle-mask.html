Particle Mask — 3-layer material

primary (body) + secondary (inner accent) + shine (original pixel colours, locked). Three sibling divs -- not pseudo-elements -- so each layer's mask is truly independent. Same particle, any colour combination, no new art required. CSS var inheritance means any new particle only needs 4 vars overridden on the wrapper.

Architecture note. The three-sibling pattern is the web equivalent of layered material channels in Unreal. Per-particle mask switching costs zero new CSS -- set 4 vars on the wrapper div and every child layer resolves to that particle's masks automatically via CSS inheritance. To add a new particle to the system: generate it, run gen_particle_mask.py, add 4 CSS vars to :root, done.

Threshold tuning. Run gen_particle_mask.py <name> --mid N --shine N to shift the zone boundaries. The right values depend on the particle's luminance distribution -- check the buckets first.
