Achievement Detail v2 . stacked vs drill-down addressing the "modal of a modal" concern . 2026-05-27

Both flavors keep the Trophy Plaque visual language (brass medallion, vermillion ribbon, MSZ glyph watermark, Cinzel + lacquer). The only thing that differs is where the plaque lives: a true second overlay (A1), or a body-swap inside the existing Codex modal (A2 . single-layer drill-down).

Where the game already opens detail surfaces (precedent)

Crystal detailTap crystal level chip on Home → centered DetailModal opens over Home. Detail = brass medallion + tier silhouette.
Producer detailTap a Pavilion Plaque in Cultivation → DetailModal opens over the Cultivation screen.
Karmic Charm detailTap a charm in Cultivation > Sparks tab → .charm-detail-overlay opens over the Sparks tab inside the screen.
Buffs modalTap the buff chip on Home → modal opens over Home with the active-buff list.
Tutorial cardFires from any context (including over the Codex) → modal stacks above whatever's open.
ToastsAlready stack on top of every surface, including modals.

Three of those open detail modals over a parent screen; tutorials and toasts already stack over modals. Achievement is the only "tap to inspect" surface currently using an inline drawer. Switching to either flavor below brings it into the established "tap → detail surface" family.

Verdict . my recommendation

Both are valid and use the same Trophy Plaque vocabulary. The "modal of a modal" worry from A1 is genuinely answered by A2's drill-down, which keeps the player in one overlay the whole time. It also gives the plaque a bigger canvas which makes the trophy moment land harder.

Go with A2 (Drill-down). One overlay, explicit Back, big plaque. The Tutorial card and Buffs / Crystal modals stay as the precedent for "true overlay" (they all open from a non-modal Home screen, so no stacking). The Codex specifically gets a drill-down because its parent is already a modal . single layer is more honest UX.

Same component, different mount point. The plaque visual is one file (AchievementPlaque.jsx); A2 renders it inline in the Codex body, A1 would have rendered it in a portal scrim. Switching between flavors later is a one-line change.
