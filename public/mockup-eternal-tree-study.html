Image-aware variants. Each node holds a real game sprite as a stand-in for the upgrade's eventual dedicated icon.
Cosmic Ledger

Indigo void with a soft scrim around each node so the sprite is not fighting the starfield. The ring carries the state: dim violet for locked, brighter violet halo for available, gold ring + gold glow for anchored. Locked sprites are desaturated and dimmed; anchored ones get a slight saturation lift.

Same 7 nodes in every variant: Devoted Path / Crystalline / Frugal anchored, Discerning Eye available next, Star Disciple / Resonance / Guidance still bound. Sprites are real game pixel art used as placeholders for the eventual dedicated upgrade icons.
